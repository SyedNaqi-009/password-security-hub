Frequently Asked Questions

What is a hash function?

A hash function is a mathematical algorithm that maps data of arbitrary size to a bit string of a fixed size (a hash).

Is MD5 still secure?

No, MD5 is considered cryptographically broken and is susceptible to collision attacks. It should not be used for security purposes.

What is the difference between SHA-256 and SHA-512?

SHA-256 outputs a 256-bit hash, while SHA-512 outputs a 512-bit hash. SHA-512 provides a higher level of security and can be faster on 64-bit systems.

Can a hash be reversed?

No, cryptographic hash functions are one-way functions. You cannot deduce the original input from the hash value.

Why do files have the same hash?

If two files produce the exact same hash, they contain exactly the same data. This is widely used for verifying file integrity after downloads.

Is my data sent to a server?

No, all hashing is performed locally in your web browser using JavaScript and the Web Crypto API. No data is sent to our servers.
